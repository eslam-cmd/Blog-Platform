# مدونة إسلام هدايا

مشروع المدونة مبني باستخدام Next.js App Router. تعرض الصفحة الرئيسية المقالات والتصنيفات، وتدعم صفحات المقالات وMarkdown.

## التشغيل

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

## مصدر المقالات

يجلب المشروع المقالات من واجهة المنصة. يمكن تغيير عنوان الواجهة عبر متغير البيئة `NEXT_PUBLIC_API_URL`، والقيمة الافتراضية هي واجهة المنصة المنشورة.

المسارات:

- `/` صفحة المدونة الرئيسية.
- `/blog/[slug]` صفحة المقالة.
- `/blog/category/[category]` مقالات التصنيف.

المسار `/blog` القديم يعيد التوجيه إلى الصفحة الرئيسية.
